# DiatomicEA

**Fast and reproducible electron-affinity calculations for diatomic molecules.**

DiatomicEA is a scientific Python project for automated electron-affinity
calculations of diatomic molecules.

The project is currently under active development.

## Goals

- simple definition of diatomic molecules
- reproducible electron-affinity calculations
- automated CPU-resource management
- calculation queues
- smoke tests
- progress reporting
- CSV output
- graphical user interface
- command-line interface

## Status

Early development.
